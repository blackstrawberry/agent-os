# agent-os alias map (optional, per project).
#
# One concept per line:   canonical: alias, alias, ...
# When any term on a line appears in the query, every term on that line joins the
# search. Documents are NEVER rewritten -- only the query grows, so adding a line
# costs nothing and retagging hundreds of documents is never needed.
#
# A line scores ONCE per field no matter how many of its terms a document carries,
# so a long alias list cannot inflate a match.
#
# Rules
# - Only put TRANSLATIONS of the same concept on one line. Related-but-different
#   concepts (test vs verification, auth vs authorization) belong on separate lines;
#   merging them is how an alias map starts producing false positives.
# - ASCII aliases shorter than 4 characters are matched at word boundaries, so "db"
#   will not fire inside "adb". CJK terms are matched as substrings, because Japanese
#   queries have no spaces to split on.
# - Project nouns (a product name, a customer name, a table name) do NOT belong here.
#   They are already unique; aliasing them only adds noise.
#
# Seeded from the area terms actually in use across the installs. Trim what your
# project does not use, and add the axes it does.
